# MLVA_finder compatibility oracle

`expected.csv` was generated from `assembly.fasta` and `primers.tsv` with
i2bc/MLVA_finder commit `15dacfc413b7fcb8c432c1cc8700e27e643ce0c3`:

```bash
python MLVA_finder.py \
  --input INPUT_DIRECTORY \
  --output OUTPUT_DIRECTORY \
  --primer primers.tsv \
  --contig
```

The fixture exercises exact products, a one-error primer product, strict
half-unit rounding, multiple FASTA records, and MLVA_finder's last-matching
record selection rule. mlvamaps runs the same fixture with multiple PCR workers
to ensure parallel discovery does not alter result order.

`fastq_output.csv` is the unmodified detailed CSV from the same upstream commit,
run with `--contig`, the default two primer mismatches, default 0.25 rounding,
and no binning. The downloaded upstream script's SHA-256 was
`61d922dbfa7006c8e10ed11b19a114df41e4b6f6f07e9676683d6ea8329f5b45`.
Its inputs are generated by `make_oracle_inputs` in
`tests/test_mlva_finder_concordance.py` (random seed 554938); all DNA is synthetic.
The six loci cover whole-unit alleles, both strict quarter-unit rounding
boundaries, a primer substitution, a primer insertion, and reverse orientation.
The reference alleles are five repeats; observed alleles differ from them.

The regression compares this independent output with assembly calls and both
single-read and paired-read SR calls, checking allele and product size exactly.
It needs no network or upstream script at test time. To regenerate the oracle,
call `make_oracle_inputs(Path('INPUT_ROOT'))`, then run the pinned script:

```bash
python MLVA_finder.py --input INPUT_ROOT/assemblies --output OUTPUT_DIRECTORY \
  --primer INPUT_ROOT/primers.tsv --contig
```

The expected artifact is `OUTPUT_DIRECTORY/assemblies_output.csv`. The fixture
uses known synthetic assemblies; it does not benchmark a whole-genome assembler
or establish agreement for a real library.

`fastq_unrounded_output.csv` was generated from the identical inputs and pinned
script with `--round 0`. Tests check both settings, including integer values
and fractional alleles retained exactly when rounding is disabled.
